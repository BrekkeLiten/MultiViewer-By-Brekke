MultiViewer by Brekke

Bitfocus Companion — oppsettguide

Denne guiden forklarer hvordan du installerer MultiViewer og styrer den fra Bitfocus Companion (Stream Deck, knapper, makroer osv.) via det innebygde HTTP-API-et.

1. Installer MultiViewer

  1. Åpne MultiViewer-by-Brekke.dmg.
  2. Dra MultiViewer by Brekke inn i Programmer.
  3. Løs ut diskavbildningen.

Første oppstart (usignert app): macOS kan blokkere appen. Høyreklikk appen i Programmer → Åpne → Åpne igjen. Dette trengs bare én gang.

NDI-kilder: MultiViewer inkluderer ikke NDI-runtime. Installer NDI Tools for macOS på samme Mac hvis du bruker NDI-innganger.

SDI (DeckLink): Installer Blackmagic Desktop Video-drivere hvis du bruker SDI-maskinvare.

2. Slå på kontrollserveren

  1. Start MultiViewer by Brekke.
  2. Åpne Innstillinger (⌘ , eller menyen MultiViewer by Brekke → Innstillinger…).
  3. Under Control (Kontroll):
    • Kryss av for Enable control server (Aktiver kontrollserver).
    • Velg Listen on (Lytt på) — se tabellen under.
    • Sett Port (standard 8080).
  4. Noter URL som vises i Innstillinger — det er grunnadressen for Companion-knapper.

Innstillingene lagres automatisk.

Hvilken «Listen on»-adresse?

InnstillingBruk når
Localhost (127.0.0.1)Companion kjører på samme Mac som MultiViewer.
Wi‑Fi / Ethernet (LAN-IP)Companion kjører på en annen datamaskin på samme nettverk (f.eks. Stream Deck-PC).
All interfaces (0.0.0.0)Lytt på alle grensesnitt; URL-en som vises bruker din første LAN-IP.

Eksempel-URL: http://192.168.0.185:8080

Bruk Copy URL i Innstillinger når du lager Companion-handlinger.

3. Installer Companion

  1. Last ned og installer Companion fra bitfocus.io/companion.
  2. Åpne Companion-administrasjonssiden i nettleseren (vanligvis http://127.0.0.1:8000 på Companion-maskinen).
  3. Opprett eller åpne en knappeside for Stream Deck / overflaten din.

Companion trenger ikke en egen MultiViewer-modul. Bruk generiske HTTP-handlinger.

4. Legg til HTTP-knappehandlinger

For hver knapp legger du til en handling som sender en HTTP-POST-forespørsel til MultiViewer.

Det nøyaktige navnet på handlingen avhenger av Companion-versjonen, for eksempel:

  • Generic HTTP Request
  • HTTP Request
  • Modul: companion-generic-http
FeltVerdi
MethodPOST
URLFull URL (se eksempler under)
BodyLa stå tom
Headers / authIkke nødvendig

Bytt ut vert og port med URL-en fra MultiViewer Innstillinger.

Layout-knapper

KnappidéURL
4-up multiviewhttp://192.168.0.185:8080/layout/4
1-up (full skjerm)http://192.168.0.185:8080/layout/1
1-up, vis spor 2http://192.168.0.185:8080/layout/primary/2

primary velger hvilket inngangsspor (1–4) som fyller skjermen i 1-up-modus.

Tilordne kilde til et spor

URL-mønster:

POST /source/{spor}/{kilde}

{spor} er 1, 2, 3 eller 4.

{kilde} er samme tekst som i Configure inputs (Konfigurer innganger), for eksempel:

  • ndi:OBS (Program) — NDI-kildenavn etter ndi:
  • ndi:192.168.1.10:5961 — direkte NDI IP-tilkobling
  • sdi:0 — første DeckLink-enhet

Viktig: Spesialtegn i URL-en må prosentkodes:

TegnKodet
:%3A
Mellomrom%20
(%28
)%29

Tips: Åpne Configure inputs… (⇧ ⌘ I) i MultiViewer for å se nøyaktige NDI/SDI-navn, og kod dem deretter i URL-en.

5. Test med curl (valgfritt)

På maskinen som når MultiViewers kontroll-URL:

# 4-up layout
curl -X POST 'http://192.168.0.185:8080/layout/4'

# 1-up layout
curl -X POST 'http://192.168.0.185:8080/layout/1'

# Les gjeldende layout (GET)
curl 'http://192.168.0.185:8080/state'

Vellykkede kommandoer returnerer JSON som {"ok":true}.

6. API-referanse (kort)

Grunn-URL: http://VERT:PORT (fra Innstillinger)

MetodeStiEffekt
GET/stateJSON: gjeldende layout og primarySlot
POST/layout/1Bytt til 1-up
POST/layout/4Bytt til 4-up
POST/layout/primary/{1-4}Hvilket spor som er fullskjerm i 1-up
POST/source/{spor}/{navn}Tilordne NDI/SDI-kilde til spor

Feil returnerer HTTP 400 med {"ok":false,"error":"…"}.

Tomme spor fjernes i appen (Configure inputs → (None)); det finnes foreløpig ingen HTTP-rute for å tømme et spor.

7. Feilsøking

ProblemSjekk dette
Knappen gjør ingentingMultiViewer kjører; Enable control server er på; URL vert/port matcher Innstillinger.
Companion på annen PC får ikke kontaktListen on må være Mac-ens LAN-IP eller All interfaces, ikke bare localhost. Brannmur må tillate innkommende TCP på porten.
127.0.0.1 fra ekstern Companion127.0.0.1 betyr alltid «denne maskinen» — bruk MultiViewers Wi‑Fi/Ethernet-IP i stedet.
Kildeknapp feilerKod : og mellomrom i URL-en; bruk nøyaktig NDI-navn fra Configure inputs.
Port i brukEndre Port i Innstillinger (f.eks. 8081) og oppdater alle Companion-URL-er.

8. Eksempel på Companion-side

Et enkelt show-oppsett kan bruke:

  1. 4-up — POST …/layout/4
  2. Kam 1 full — POST …/layout/1 deretter POST …/layout/primary/1
  3. Program på spor 1 — POST …/source/1/ndi%3A…
  4. Preview på spor 2 — POST …/source/2/ndi%3A…

Bygg URL-ene én gang, dupliser knapper, og endre spor eller kodete kildenavn etter behov.
